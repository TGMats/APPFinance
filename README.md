# Personal Finance Tracker

A desktop-based personal finance management application developed in Python, designed to help users manage income, recurring expenses, savings, investments and monthly budgets. Built with an emphasis on reliable local data management, automation and clear financial visualisation.

## Features

- **Multi-User Profiles:** Separate financial profiles for multiple users, allowing individual income, expenses, savings and allocations to be managed independently.
- **Income Management:** Record and manage income, with automatic allocation towards configured financial categories.
- **Recurring Bills:** Track monthly bills and recurring expenses, with configurable amounts and payment allocations.
- **Budget Management:** Organise finances into categories such as bills, savings, investments and discretionary spending.
- **Savings & Investment Tracking:** Monitor contributions and financial progress towards savings and investment goals.
- **Financial Visualisation:** Interactive charts and progress indicators provide an overview of monthly allocations, spending and financial targets.
- **Monthly Financial Planning:** Manage monthly budgets and track available funds against recurring commitments.
- **Data Persistence:** SQLite database integration for structured local storage and reliable data management.
- **Import & Export:** Support for transferring financial data and maintaining accessible records.
- **Undo Functionality:** Revert supported changes to help prevent accidental data modifications.

## Technical Implementation

Developed using Python, with a modular application structure and a Tkinter graphical interface. SQLite handles local data persistence, while Matplotlib provides financial charts and visual reporting.

The application prioritises offline functionality, structured data handling and straightforward workflows, without requiring external financial services or cloud infrastructure.

## Technologies

- Python
- Tkinter
- SQLite

## Project Goals

The project was developed to explore practical software engineering concepts through a real-world application, focusing on database design, financial calculations, GUI development, state management and maintainable application architecture.
